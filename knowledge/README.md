# Knowledge

Use these notes when generating or reviewing MoonCraft apps. Keep each file
short and tied to behavior that can be validated in a generated project.

- `mooncraft-runtime.md`: preview and validation contract.
- `moonbit-multiple-targets.md`: frontend/shared/backend guidance.
- `moonbit-style.md`: MoonBit conventions that matter for generated apps.
- `template-authoring.md`: expectations for templates in this repository.
